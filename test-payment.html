🐛 Common Issues & Solutions

Issue: "Order not found"

Solution: Check if order was created in database. Verify API endpoint responses.

Issue: Payment not processing

Solution: Check Socket.IO connection. Verify WebSocket server is running.

Issue: Location not working

Solution: Check browser permissions. Test with HTTPS.

Issue: Delivery fee not calculating

Solution: Check restaurant coordinates in database. Verify geocoding API calls.
